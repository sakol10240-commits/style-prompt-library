# style-prompt-library
style-prompt-library สำหรับทำเพลงในโปรแกรม Suno ai สามารถใช้งานได้ฟรี ติดตั้งผ่านบราวเซอร์ โดย ร้านชำพี่หนึ่ง
สร้างเพลงใหม่, หรือทำเพลงบรรเลง
ค้นหาและเลือกแนวเพลงหลายแนว 
พร้อมแนวเพลงที่ผู้ใช้เพิ่มเอง
เลือกเสียงร้อง ภาษา และความยาวเพลง
สร้าง Style prompt, Exclude Styles และเนื้อเพลงที่จัดแท็กแล้ว
คัดลอกผลลัพธ์และบันทึก/เรียกคืน/ลบรายการในคลังเพลงบนอุปกรณ์
